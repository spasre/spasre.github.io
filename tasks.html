任务板

添加任务时可以选分类和紧急程度，也可以给任务排个日期，任务会按「已逾期 / 今天 / 明天 / 本周内 / 以后 / 未排期」分组。点任务左边的小狗表示完成，任务会被叼进回收站，可以恢复，也可以永久清除。

    助手

    不填模型也能用：内置规划会把一段话拆成任务，认日期（今天 / 明天 / 周三 / 10-12）、紧急程度和分类；问它「今天有什么任务」这类问题，它会直接读任务板回答。填上模型接口后，改由你自己的模型来拆解和规划，结果直接写进任务板。

    地址填 OpenAI 兼容的根路径，会自动补 /chat/completions：DeepSeek、Moonshot、Groq、SiliconFlow、Ollama（http://localhost:11434/v1）都可以。测试通过后这几栏会收起来，要改点「设置」（要先过密码）。

    自定义接口（高级）

    不用 OpenAI 兼容格式时可以填自己的地址，填了就优先用它。请求体是 { prompt, today, categories, tasks }，返回 { "tasks": [{ "title", "category", "urgency", "date" }] } 或 { "reply": "..." }。也可以在控制台调用 spasreTasks.ask("...")。
