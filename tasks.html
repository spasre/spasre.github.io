任务板

添加任务时可以选分类和紧急程度，也可以给任务排个日期，任务会按「已逾期 / 今天 / 明天 / 本周内 / 以后 / 未排期」分组。点任务左边的小狗表示完成，任务会被叼进回收站，可以恢复，也可以永久清除。

    AI 助手（接口预留）

    填好接口地址后，可以让助手读当前任务、把下一步写进任务板。请求体是 { prompt, today, categories, tasks }，返回 { "tasks": [{ "title", "category", "urgency", "date" }] } 就会自动加进来。也可以直接在控制台调用 spasreTasks.requestPlan("帮我规划这周")。
