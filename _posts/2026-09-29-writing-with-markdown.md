你好，欢迎来到我的博客。

从现在开始，可以把想法写进 Markdown 文件，再放进 `_posts` 目录。每篇文章都会拥有自己的页面，也会自动出现在首页的文章列表和搜索结果里。

## 为什么用 Markdown

Markdown 让人专注于内容本身。用 `#` 写标题、用 `-` 列清单，也可以加入链接、图片和代码。

```text
_posts/YYYY-MM-DD-your-post-title.md
```

保存并推送到 GitHub 后，GitHub Pages 会负责生成并发布页面。
